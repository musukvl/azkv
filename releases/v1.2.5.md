# Azure Key Vault Manager v1.2.5

## Terminal.Gui 2.4.17 Upgrade

This release upgrades Terminal.Gui to the latest stable version `2.4.17` and migrates the theme system to the new Microsoft.Extensions.Configuration-based API.

## What's New

### Dependency Upgrades

- Updated `Terminal.Gui` from `2.4.7` to `2.4.17` — ten patch releases of fixes, including `FileDialog`/`OpenDialog` no longer rendering an empty directory when a single entry is unreadable, dotfiles remaining visible in file dialogs, `Padding` adornment no longer filling with a stale attribute, `DropDownList` using a distinct background, and layout-convergence hardening.

### Theme System Migration

- Migrated theme handling off the deprecated `ConfigurationManager` onto `TuiConfigurationBuilder` and `IThemeManager`. Terminal.Gui 2.4.15 replaced `ConfigurationManager` with Microsoft.Extensions.Configuration and 2.4.17 marked the old API obsolete; the app now uses the supported `ThemeManager.ThemeNames` / `SwitchTheme` surface.
- Theme discovery and switching behavior is unchanged — all built-in themes (Default, 8-Bit, Amber Phosphor, Anders, Dark, Green Phosphor, Light, TurboPascal 5) remain available via `--theme` and the Theme menu.

### Documentation

- Updated Terminal.Gui repository links to the project's new `tui-cs` organization.

## Installation

### Homebrew (macOS/Linux)

```bash
brew tap musukvl/azkv
brew upgrade azkv
```

### .NET Tool

```bash
dotnet tool install -g azkv
```

### Direct Download

Download the appropriate binary for your platform:

- **macOS (Apple Silicon)**: [azkv-1.2.5-osx-arm64.tar.gz](https://github.com/musukvl/azkv/releases/download/v1.2.5/azkv-1.2.5-osx-arm64.tar.gz)

### Extract and Run

**macOS/Linux:**
```bash
tar -xzf azkv-1.2.5-*.tar.gz
chmod +x azkv
./azkv
```

**Windows:**
```powershell
Expand-Archive azkv-1.2.5-win-x64.zip
cd azkv-1.2.5-win-x64
.\azkv.exe
```
